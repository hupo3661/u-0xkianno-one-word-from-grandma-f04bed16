An entry for the make.fun competition `u-0xkianno-one-word-from-grandma-f04bed16`
("One Word From Grandma"). `main.py` (Python 3, standard library only, no
network) writes exactly one word — the word a grandma would text about AI —
to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).

The word is `knowitall`: the gentle, slightly baffled label a grandma gives
the machine that seems to know everything — warm, funny, and tied to what
makes AI itself, not just any gadget.

The output is UTF-8 text of 9 characters, within the competition's 1–30
character limit.

## Run it

```sh
python3 main.py
```
